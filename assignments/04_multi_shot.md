# Assignment: Multi-Shot Prompting

## Practical task

Write a multi-shot prompt that asks the model to classify support tickets into categories such as Billing, Technical Issue, Account Access, or General Inquiry.

## Rules
Include 5–8 examples in the prompt.
Keep the task focused on support ticket classification.
Make the final instruction clear and follow the example pattern.

## What will be checked
The prompt includes multiple examples (more than few-shot).
Each example demonstrates the correct classification.
The final prompt asks for classification of a new ticket.
The task is realistic and achievable with multi-shot learning.
