## 🎯 Practical Task

Create two versions of a prompt for this scenario:

👉 A person earns ₹55,000 per month  
👉 Expenses are ₹35,000  

---

### 🧾 Requirements

- **Version 1**: Simple prompt  
- **Version 2**: Improved structured prompt  

Task:
- Calculate savings  
- Suggest a simple savings plan  

---

## 📏 Rules

- Version 1 should be **basic and short**
- Version 2 should include:
  - Role  
  - Task  
  - Context  
  - Constraints  
  - Output Format  
- Keep both prompts **clear and readable**

---

## ✅ What will be checked

- ✔️ Clear difference between both versions  
- ✔️ Improved structure in Version 2  
- ✔️ Better clarity and output quality  
- ✔️ Logical and correct task  

---

## 🚀 Goal

👉 Learn how to **refine prompts for better performance**
