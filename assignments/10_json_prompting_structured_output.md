## 🎯 Practical Task

Create a JSON prompt for this scenario:

👉 Generate a weekly workout plan for a beginner  

---

### 🧾 Requirements

The output JSON must include:
- "goal"
- "level"
- "days" (list)

Each day should have:
- "day"
- "exercise"
- "duration_minutes"

---

## 📏 Rules

- Return **only valid JSON**
- Do not include markdown or explanations  
- Create exactly **3 days**
- Keep tasks **simple and realistic**

---

## ✅ What will be checked

- ✔️ Proper JSON structure  
- ✔️ Valid and parsable output  
- ✔️ Clear and realistic tasks  
- ✔️ No extra text outside JSON  

---

## 🚀 Goal

👉 Learn how to get **structured and machine-readable responses**
