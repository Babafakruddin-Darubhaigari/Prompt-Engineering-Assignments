# Assignment: One-shot Prompting

## Practical task
Write a one-shot prompt that asks the model to turn an informal email sentence into a professional sentence.

## Rules
- Include exactly one example in the prompt.
- Keep the task short and realistic.
- Make the final instruction clear.

## What will be checked
- The prompt includes one example and not multiple examples.
- The example matches the task being asked.
- The final prompt is clear enough for the model to follow the pattern.
