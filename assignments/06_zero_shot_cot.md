## **06_zero_shot_cot_assignment.md**

### 🎯 Practical Task

Create a prompt using **Zero-Shot Chain of Thought** to solve this problem:

👉 A person earns ₹30,000 per month
👉 Monthly expenses are ₹18,000

Calculate:

* Monthly savings
* Total savings in 1 year

Your prompt **must ask the model to think step by step**.

---

### 📏 Rules

* Do **not** provide any examples in the prompt
* You **must include** a reasoning instruction like:

  * *"Let's think step by step"*
* Keep the prompt **clear and simple**
* Use **realistic numbers**
* Output should be generated using `model.generate(prompt)`

---

### ✅ What Will Be Checked

* ✔️ Correct use of **Zero-Shot CoT technique**
* ✔️ Clear and structured prompt
* ✔️ Presence of step-by-step reasoning instruction
* ✔️ Logical and correct calculation in output
* ✔️ Clean and readable code
