## 🎯 Practical Task

Create a good prompt for this scenario:

👉 A person earns ₹50,000 per month  
👉 Expenses are ₹30,000  

Task:
- Calculate savings  
- Suggest a simple savings plan  

---

## 📏 Rules

- Keep the prompt **clear and short**
- Include a **role (optional but recommended)**
- Do **not add unnecessary details**
- You can include: *"Let's think step by step"*

---

## ✅ What will be checked

- ✔️ Clear and focused prompt  
- ✔️ No unnecessary information  
- ✔️ Correct task definition  
- ✔️ Logical and structured output  

---

## 🚀 Goal

👉 Learn how to write **simple but effective prompts**
