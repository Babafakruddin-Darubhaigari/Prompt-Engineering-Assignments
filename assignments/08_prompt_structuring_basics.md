## 🎯 Practical Task

Create a structured prompt using these sections:

- Role  
- Task  
- Context  
- Constraints  
- Output Format  

---

### 🧾 Scenario

👉 A person earns ₹60,000 per month  
👉 Monthly expenses are ₹35,000  

Task:
- Calculate savings  
- Suggest a simple savings plan  

---

## 📏 Rules

- Use all 5 sections clearly  
- Keep the prompt **simple and readable**  
- Do not add unnecessary details  
- Maintain proper structure  

---

## ✅ What will be checked

- ✔️ Proper use of all sections  
- ✔️ Clear and logical structure  
- ✔️ Correct task definition  
- ✔️ Clean and readable format
