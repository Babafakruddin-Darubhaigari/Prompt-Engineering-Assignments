# Zero-shot Prompting

Zero-shot prompting means asking the model to perform a task directly, without giving any examples first.

## Example prompt

```text
What is the capital of France?
```

## Explanation

- This prompt is a direct question.
- The model must answer based only on its general knowledge.
- No examples or demonstrations are provided.

## Usage

Use zero-shot prompts when you want a simple, direct response from the model without showing it how to do the task first.
