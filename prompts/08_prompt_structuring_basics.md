## 🧠 Prompt Structuring Basics

### What it means
Prompt structuring means organizing your prompt into clear sections like:
- Role
- Task
- Context
- Constraints
- Output Format

This helps the model understand exactly what to do.

---

### When to use it
- When tasks are **slightly complex**
- When you need **consistent output format**
- When you want **better control over responses**

---

### 💡 Example

👉 Structured Prompt:
```
Role:
You are a financial advisor.

Task:
Calculate savings.

Context:
Income ₹40,000, expenses ₹25,000.

Constraints:
Explain simply.

Output Format:
- Savings: <amount>
- Explanation: steps
```

👉 What happens:
- Model understands each section clearly  
- Output becomes structured and predictable  

---

### 🚀 Key Takeaway

👉 **Structure = Better clarity = Better output**

Breaking prompts into sections improves consistency and control.
