## 🧠 Prompt Reuse & Versioning

### What it means
Prompt versioning means **improving the same prompt step by step** instead of rewriting it from scratch.

You create:
- Version 1 → basic prompt  
- Version 2 → improved prompt  

---

### When to use it
- When your output is **not clear or consistent**
- When you want to **improve response quality**
- When working on **real projects with iterations**

---

### 💡 Example

👉 Version 1:
```
Calculate savings.

Income ₹50,000, expenses ₹32,000.
```

👉 Version 2:
```
Role:
You are a financial advisor.

Task:
Calculate savings and suggest a plan.

Context:
Income ₹50,000, expenses ₹32,000.

Constraints:
Explain step by step.

Output Format:
- Savings: <amount>
- Plan: bullet points
```

👉 What happens:
- Version 1 → simple but vague output  
- Version 2 → structured and clear output  

---

### 🚀 Key Takeaway

👉 **Improve prompts, don’t rewrite them**

Small changes can significantly improve output quality.
